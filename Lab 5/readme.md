# Introduction

An SQL script containing 17 queries for a guitar database.

# Description

This lab is an SQL re-introduction. It contains a collection of query statements ranging from simple table selects, to slightly more complex inner-join and group-by statements that gather information about products, customers, orders, and more.

# Design

The project is written in SQL using DBeaver and is intended to be used with the MySQl guitar database.

There are 7 simple single table queries
There are 5 innjer join queries
There is 1 query with a function
There are 4 group by queries

# Running The Script (DBeaver)

1. Download createguitar.sql and using an SQL IDE of your choice (must support MySQL), run the script
2. Download Script.sql and import it into your chosen SQL IDE
3. Before executing the different queries, execute the USE statement at the top of script
4. Execute the remaining queries
